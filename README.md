# Metro data exploration

This is the early notebook from my passenger-flow thesis. It explores event and station-reference tables, builds Parquet extracts with DuckDB and checks station-level aggregation.

The final research code and results are in [highload-context-ensemble-forecasting](https://github.com/jeck5iv/highload-context-ensemble-forecasting). That repository covers local ETS models, pooled residual correction, temporal validation and the horizon comparison. This notebook is part of the same project.

## Data

The notebook expects closed operational CSV files that are not distributed here. Saved cell outputs have been cleared because they included source-record previews. No replacement or synthetic results have been inserted. Older outputs may still exist in Git history.

The code is retained as an exploratory record, not a maintained entry point. For runnable public checks and the final methodology, use the study repository linked above.
